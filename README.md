`make`

Il faut [GNU make](https://www.gnu.org/software/make/manual/make.html), [Pandoc](https://pandoc.org/) et [LuaLaTeX](https://www.luatex.org/) installés.

`figures/Export` est un symlink sur mon ordi, si vous voulez ajoutez une figure qui est sur le téléphone mettez son chemin dans le `md` comme étant `figures/Export/NOM_SUR_SAMSUNG.XXX`, je l'exporterai ensuite.
